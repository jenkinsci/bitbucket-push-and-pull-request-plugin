Base URL of the Bitbucket Server that receives build-status notifications, including any context path (for example https://bitbucket.example.com or https://bitbucket.example.com/bitbucket). Required for Bitbucket Server and used together with a credential: a notification is sent only when both are configured, here or on a job trigger.

Use an https URL: over plain http the credentials of the build status notifications travel unencrypted. An http URL is still accepted, for setups where TLS is terminated by a trusted proxy in front of Bitbucket, but the form shows a warning.
